Sizzle Station is a complete original 2D cooking game: take orders, grill patties, chop vegetables, assemble dishes, and serve them before patience runs out.

## Run it

```sh
python3 -m http.server 8080 --directory game
```
Open http://localhost:8080 in a desktop browser to play.
